## Статья 1: SSL/TLS — безопасность на транспортном уровне

### Что такое TLS

**TLS (Transport Layer Security)** — протокол шифрования данных между клиентом и сервером. Обеспечивает:

- **Конфиденциальность** — данные зашифрованы
    
- **Целостность** — данные нельзя изменить незаметно
    
- **Аутентификацию** — сертификат подтверждает подлинность сервера
    

### Версии протокола

|Протокол|Статус|
|---|---|
|SSL 2.0/3.0|❌ Небезопасны, отключать|
|TLS 1.0/1.1|❌ Устарели, отключать|
|TLS 1.2|✅ Актуален|
|TLS 1.3|✅ Рекомендуется (быстрее, безопаснее)|

### TLS Handshake

**TLS 1.2** — 2 round-trip

text

Client → Server: ClientHello (версии, шифры, random)
Server → Client: ServerHello + Certificate + ServerHelloDone
Client → Server: ClientKeyExchange + ChangeCipherSpec + Finished
Server → Client: ChangeCipherSpec + Finished

**TLS 1.3** — 1 round-trip (быстрее)

text

Client → Server: ClientHello + KeyShare
Server → Client: ServerHello + KeyShare + Certificate + Finished
Client → Server: Finished

### Сертификаты X.509

**Что внутри:** Subject (кому выдан), Issuer (кто выдал), Validity (срок), Public Key, SAN (дополнительные домены), Signature (подпись CA)

**SAN (Subject Alternative Name)** — современный способ указать несколько доменов в одном сертификате:

text

X509v3 Subject Alternative Name: DNS:example.com, DNS:www.example.com, DNS:api.example.com

**Wildcard-сертификат:** `*.example.com` покрывает `www.example.com`, но не `example.com` и не `sub.api.example.com`

### Типы сертификатов по валидации

|Тип|Проверка|Срок выпуска|Пример|
|---|---|---|---|
|**DV**|Только владение доменом|Минуты|Let's Encrypt|
|**OV**|Проверка организации|Дни|Коммерческие CA|
|**EV**|Расширенная проверка|Дни/недели|Банки, гос. сайты|

### Цепочка доверия

text

[Ваш сертификат] ← подписан ← [Intermediate CA] ← подписан ← [Root CA]
                                                              ↓
                                                    (в браузере/ОС)

Сервер должен отдавать: свой сертификат + все intermediate. Root — не нужно (уже у клиента).

### Let's Encrypt

Бесплатные DV-сертификаты на 90 дней. Автоматическое обновление через certbot.

bash

certbot --nginx -d example.com -d www.example.com   # получить
certbot renew                                        # обновить

### Диагностика

# Проверить цепочку

## Статья 2: MAC, ARP, VLAN — канальный уровень

### MAC-адреса

**MAC (Media Access Control)** — уникальный физический адрес сетевого интерфейса (6 байт, hex).

text

00:1A:2B:3C:4D:5E
└─OUI─┘ └─серийный номер─┘
OUI — идентификатор производителя (первые 3 байта)

**Специальные MAC-адреса:**

- `FF:FF:FF:FF:FF:FF` — broadcast (всем в сегменте)
    
- `01:00:5E:xx:xx:xx` — multicast (группам)
    

### ARP — Address Resolution Protocol

**Зачем:** Превращает IP-адрес в MAC-адрес (в пределах одной локальной сети).

**Как работает:**

text

Хост A (192.168.1.10) → broadcast "Кто имеет IP 192.168.1.20?"
Хост B (192.168.1.20) → unicast "Я, мой MAC — aa:bb:cc:dd:ee:ff"

**ARP-кэш:**

bash

arp -n                    # посмотреть кэш
ip neigh show             # современная команда
ping 192.168.1.20         # инициирует ARP-запрос

**Состояния ARP-записей:** REACHABLE (подтверждён) → STALE (давно не проверялся) → FAILED

**ARP и шлюз:** При отправке в другую сеть (например, в интернет) хост делает ARP на **шлюз**, а не на конечный IP.

### VLAN — виртуальные локальные сети

**Зачем:** Логически разделить одну физическую сеть на несколько изолированных сегментов.

**Access port** — порт принадлежит одному VLAN (устройство не знает о VLAN)

**Trunk port** — передаёт трафик нескольких VLAN с тегами (802.1Q)

**802.1Q тег** (4 байта):

- TPID (0x8100) — указатель, что это VLAN-кадр
    
- PCP (3 бита) — приоритет
    
- DEI (1 бит) — флаг
    
- VLAN ID (12 бит) — номер VLAN (1-4094)
    

**Что дают VLAN:**

- Безопасность (изоляция отделов)
    
- Производительность (меньше broadcast-трафика)
    
- Гибкость (логическая структура не зависит от физической)
    

### Что запомнить

1. **MAC** — физический адрес (6 байт, вшит в железо)
    
2. **ARP** — IP → MAC (работает только внутри локальной сети)
    
3. **VLAN** — изоляция трафика на L2 (теги 802.1Q)
    
4. **TLS 1.3** — текущий стандарт (быстрее, безопаснее)
    
5. **Let's Encrypt** — бесплатные сертификаты на 90 дней
    
6. **openssl s_client** — главный инструмент диагностики TLS
