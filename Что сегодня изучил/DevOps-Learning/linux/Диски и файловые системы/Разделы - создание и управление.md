### Зачем нужны разделы?

Разделы позволяют логически разделить физический диск на н**езависимые части**. Каждый раздел может иметь свою файловую систему и использоваться для разных целей.

Типичные причины создания разделов:

- **Изоляция системы от данных** — если переполнится раздел с пользовательскими файлами, система продолжит работать
- **Мультизагрузка** — установка нескольких операционных систем на один диск
- **Разные файловые системы** — один раздел `ext4` для Linux, другой `NTFS` для обмена с Windows
- **Упрощение резервного копирования** — можно бэкапить только важные разделы
- **Безопасность** — можно монтировать разделы с разными правами доступа

```bash
Физический диск 500GB:
┌────────────────────────────────────────────────┐
│ Раздел 1   │ Раздел 2 │   Раздел 3   │ Раздел 4│
│ /boot      │ swap     │   /          │ /home   │
│ 1GB        │ 8GB      │   50GB       │ 441GB   │
│ ext4       │ swap     │   ext4       │ ext4    │
└────────────────────────────────────────────────┘
```

### Таблицы разделов: MBR vs GPT

Прежде чем создавать разделы, нужно понять, что существует два типа таблиц разделов.

**MBR (Master Boot Record)** — старый стандарт:

- Максимум **4** основных раздела (или 3 основных + расширенный с логическими)
- Максимальный размер диска — **2TB**
- Совместим со старыми системами

**GPT (GUID Partition Table)** — современный стандарт:

- До 128 разделов (в Linux)
- Диски размером до 9.4 зеттабайт
- Более надёжный (хранит резервные копии таблицы)
- Требует UEFI для загрузки (или специальный загрузчик для BIOS)

Чтобы узнать, какая таблица на диске, используем команду `sudo fdisk -l /dev/sda`:

```bash
$ sudo fdisk -l /dev/sda
Disk /dev/sda: 238.47 GiB, 256060514304 bytes
Disklabel type: gpt           # ← Вот тип таблицы
Disk identifier: 1234-5678-90AB-CDEF
```

### Основные инструменты для работы с разделами

В Linux есть несколько программ для управления разделами. Мы рассмотрим две основные:

- **fdisk** — классическая утилита, текстовое меню, подходит для MBR и GPT
- **parted** — более современная, поддерживает больше операций

Также существуют графические программы вроде GParted, но важно уметь работать из командной строки — графика не всегда доступна.

### Работа с fdisk

Работает в интерактивном режиме: вы запускаете её, вводите команды, и только в конце применяете изменения.

Запуск `fdisk`:

```applescript
$ sudo fdisk /dev/sdb

Welcome to fdisk (util-linux 2.37.2).
Changes will remain in memory only, until you decide to write them.
Be careful before using the write command.

Command (m for help):
```

Основные команды `fdisk`:

```css
m — показать справку
p — показать текущие разделы
n — создать новый раздел
d — удалить раздел
t — изменить тип раздела
w — записать изменения и выйти
q — выйти без сохранения
```

**Важно:** пока вы не нажали `w`, все изменения только в памяти. Это защита от случайных ошибок.

### Создание нового раздела с fdisk

Давайте создадим раздел на новом диске. Предположим, у нас есть пустой диск `/dev/sdb` размером 100GB:

```sql
$ sudo fdisk /dev/sdb

Command (m for help): p
Disk /dev/sdb: 100 GiB, 107374182400 bytes
# Диск пустой, разделов нет

Command (m for help): g
Created a new GPT disklabel.

Command (m for help): n
Partition number (1-128, default 1): [Enter]
First sector (2048-209715166, default 2048): [Enter]
Last sector (2048-209715166, default 209715166): +20G

Created a new partition 1 of type 'Linux filesystem' and size 20 GiB.

Command (m for help): p
Device     Start      End  Sectors Size Type
/dev/sdb1   2048 41945087 41943040  20G Linux filesystem

Command (m for help): w
The partition table has been altered.
Syncing disks.
```

Что мы сделали:

1. `g` — создали новую GPT таблицу разделов
2. `n` — начали создание нового раздела
3. Приняли номер по умолчанию (1)
4. Приняли начальный сектор по умолчанию
5. Указали размер `+20G` (можно также указать конечный сектор или процент)
6. `w` — записали изменения на диск

### Способы указания размера раздела

При создании раздела можно указать размер разными способами:

```yaml
# Фиксированный размер
Last sector: +10G      # 10 гигабайт
Last sector: +500M     # 500 мегабайт
Last sector: +2T       # 2 терабайта

# Процент от свободного места
Last sector: +50%      # Половина свободного места

# Конкретный сектор
Last sector: 41945087  # Номер последнего сектора

# Всё оставшееся место
Last sector: [Enter]   # Просто нажать Enter
```

### Создание нескольких разделов

Теперь создадим типичную разметку для сервера: **отдельные разделы для системы, данных и swap**:

```yaml
$ sudo fdisk /dev/sdb

# Создаём первый раздел для /boot
Command: n
Partition number: 1
First sector: [Enter]
Last sector: +1G

# Создаём второй раздел для swap
Command: n

First sector: [Enter]
Last sector: +8G

# Меняем тип второго раздела на swap

Partition number: 2
Partition type: 19      # 19 = Linux swap

# Создаём третий раздел для системы
Command: n
Partition number: 3
First sector: [Enter]
Last sector: +30G

# Создаём четвёртый раздел для данных (всё оставшееся)
Command: n
Partition number: 4
First sector: [Enter]
Last sector: [Enter]

# Проверяем результат
Command: p
Device     Start       End   Sectors  Size Type
/dev/sdb1   2048   2099199   2097152    1G Linux filesystem
/dev/sdb2 2099200  18876415  16777216    8G Linux swap
/dev/sdb3 18876416 81791099  62914684   30G Linux filesystem  
/dev/sdb4 81791100 209715166 127924067   61G Linux filesystem

# Сохраняем
Command: w
```

### Работа с parted

Утилита `parted` более современная и мощная. В отличие от `fdisk`, она может изменять размер разделов и работает как в интерактивном, так и в командном режиме.

Интерактивный режим:

```sql
$ sudo parted /dev/sdb
GNU Parted 3.4
Using /dev/sdb
Welcome to GNU Parted! Type 'help' to view a list of commands.

(parted) print
Model: ATA Samsung SSD (scsi)
Disk /dev/sdb: 107GB
Sector size: 512B/512B
Partition Table: gpt

(parted) mklabel gpt    # Создать GPT таблицу
(parted) mkpart primary ext4 0% 20GB   # Создать раздел
(parted) print
Number  Start   End    Size   File system  Name     Flags
 1      1049kB  20.0GB 20.0GB              primary

(parted) quit
```

Командный режим:

```shell
# Создать GPT таблицу
$ sudo parted /dev/sdb mklabel gpt

# Создать разделы
$ sudo parted /dev/sdb mkpart primary ext4 0% 20GB
$ sudo parted /dev/sdb mkpart primary linux-swap 20GB 28GB
$ sudo parted /dev/sdb mkpart primary ext4 28GB 100%

# Посмотреть результат
$ sudo parted /dev/sdb print
```

### Удаление разделов

Удаление раздела — операция **необратимая**. Все данные на разделе будут потеряны.

С помощью `fdisk`:

```yaml
$ sudo fdisk /dev/sdb

Command: p    # Смотрим список разделов
Command: d    # Команда удаления
Partition number (1-4): 3   # Удаляем раздел 3

Partition 3 has been deleted.

Command: w    # Сохраняем изменения
```

С помощью `parted`:

```shell
$ sudo parted /dev/sdb rm 3   # Удалить раздел номер 3
```

### Изменение размера разделов

Изменение размера — сложная операция. **Всегда делайте резервную копию** перед изменением размера раздела с важными данными.

Общий принцип:

- **Увеличение** — сначала увеличиваем раздел, потом файловую систему
- **Уменьшение** — сначала уменьшаем файловую систему, потом раздел

Пример увеличения раздела `ext4`:

```shell
# 1. Размонтируем раздел
$ sudo umount /dev/sdb1

# 2. Проверяем файловую систему
$ sudo e2fsck -f /dev/sdb1

# 3. Увеличиваем раздел с помощью parted
$ sudo parted /dev/sdb
(parted) resizepart 1 40GB   # Увеличиваем до 40GB
(parted) quit

# 4. Увеличиваем файловую систему
$ sudo resize2fs /dev/sdb1

# 5. Монтируем обратно
$ sudo mount /dev/sdb1 /mnt/data
```

### Выравнивание разделов

Современные диски (особенно SSD) работают эффективнее, когда разделы выровнены по границам блоков. К счастью, современные утилиты делают это автоматически. Вот почему `fdisk` предлагает начать с сектора 2048, а не с 0:

```cpp
First sector (2048-209715166, default 2048):
             ^^^^
             Выровнено по 1MB границе (2048 * 512 bytes = 1MB)
```

Проверить выравнивание можно командой:

```shell
$ sudo parted /dev/sda align-check optimal 1
1 aligned
```

### Типы разделов и их коды

Каждый раздел имеет тип, который подсказывает системе, как с ним работать. Основные типы:

```haskell
Код  Тип
1    EFI System (для UEFI загрузки)
19   Linux swap
20   Linux filesystem (по умолчанию)
11   Microsoft basic data (NTFS/FAT32)
28   Linux root (x86-64) - для systemd
```

Посмотреть все доступные типы в `fdisk`:

```haskell
Command: t
Partition number: 1
Partition type (type L to list all types): L
```

### Проверка изменений перед записью

Перед тем как нажать `w` в `fdisk`, всегда проверяйте:

1. Правильные ли размеры разделов
2. Не удалили ли случайно нужный раздел
3. Правильные ли типы разделов

Используйте команду `p` для просмотра будущей таблицы разделов. Если что-то не так — нажмите `q` для выхода без сохранения.

### Полезные команды для работы с разделами

```shell
# Обновить таблицу разделов без перезагрузки
$ sudo partprobe /dev/sdb

# Показать подробную информацию о разделах
$ sudo gdisk -l /dev/sdb    # Для GPT
$ sudo sfdisk -l /dev/sdb   # Универсальная

# Создать резервную копию таблицы разделов
$ sudo sfdisk -d /dev/sdb > partitions-backup.txt

# Восстановить таблицу разделов из резервной копии
$ sudo sfdisk /dev/sdb < partitions-backup.txt

# Скопировать таблицу разделов на другой диск
$ sudo sfdisk -d /dev/sda | sudo sfdisk /dev/sdb

# Очистить таблицу разделов (осторожно!)
$ sudo dd if=/dev/zero of=/dev/sdb bs=512 count=1
```
