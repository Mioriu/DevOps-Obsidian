### Тезисно: Файловые системы и монтирование

**1. Файловая система (Добавление структуры)**

- **Что делает:** Организует на разделе структуру для хранения имён файлов, прав доступа, времени создания и самих данных. Без ФС раздел — просто набор байтов.
    
- **Создание (форматирование):** Команда `mkfs.*`. **Важно: уничтожает все данные на разделе!**
    
    - `sudo mkfs.ext4 /dev/sdb1` — стандартная ФС Linux.
        
    - `sudo mkfs.xfs /dev/sdb2` — для больших файлов.
        
    - `sudo mkfs.ntfs /dev/sdb3` — для совместимости с Windows.
        
    - `sudo mkfs.vfat -F 32 /dev/sdb4` — для флешек.
        

**2. Монтирование (Подключение к системе)**

- **Суть:** Привязать раздел с ФС к существующей папке (точке монтирования), чтобы получить к нему доступ.
    
- **Основные команды:**
    
    - `sudo mount /dev/sdb1 /mnt/mydata` — примонтировать раздел в папку.
        
    - `sudo umount /mnt/mydata` — отмонтировать.
        
    - `df -h` — посмотреть все примонтированные разделы и свободное место.
        
- **Опции монтирования (`-o`):** Управляют поведением.
    
    - `ro` — только чтение, `rw` — чтение и запись.
        
    - `noexec` — запретить запуск программ с этого раздела.
        
    - `nosuid`, `nodev` — опции безопасности.
        
    - `noatime` — не обновлять время доступа (ускоряет работу, особенно на SSD).
        
- **Решение проблемы "target is busy":**
    
    - `lsof /mnt/mydata` или `fuser -vm /mnt/mydata` — найти процессы, использующие раздел.
        
    - `fuser -km /mnt/mydata` — убить эти процессы (осторожно!).
        

**3. Автоматическое монтирование (/etc/fstab)**

- **Зачем:** Чтобы разделы монтировались автоматически при загрузке системы.
    
- **Файл:** `/etc/fstab`. Каждая строка — правило монтирования.
    
- **Формат строки:** `<устройство> <точка_монтирования> <тип_ФС> <опции> <dump> <pass>`
    
- **Идентификация устройства:**
    
    - `/dev/sda1` — ненадежно (имена могут меняться).
        
    - **UUID (универсальный идентификатор)** — лучший способ. Не меняется. Узнать: `blkid` или `ls -l /dev/disk/by-uuid/`.
        
    - `LABEL` — метка, которую можно задать самому (`e2label /dev/sdb1 "MyDisk"`).
        
- **Полезные опции для fstab:**
    
    - `defaults` — стандартный набор (rw, suid, dev, exec, auto, nouser, async).
        
    - `nofail` — не останавливать загрузку, если устройство отсутствует (для съемных дисков).
        
    - `noauto` — не монтировать автоматически при загрузке, только вручную.
        
    - `user` — разрешить монтировать обычному пользователю.
        
- **Проверка:** После редактирования fstab выполнить `sudo mount -a`. Если ошибок нет — всё правильно.
    

**4. Специальные типы монтирования**

- **Bind mount (`--bind`):** Монтирует существующую папку в другое место. По сути, делает её содержимое доступным по второму пути. `sudo mount --bind /original/dir /new/place`.
    
- **tmpfs:** Файловая система в оперативной памяти. Очень быстрая, но данные исчезают после перезагрузки. Идеально для `/tmp`. `sudo mount -t tmpfs -o size=2G tmpfs /mnt/ramdisk`.
