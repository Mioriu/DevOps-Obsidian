Перед началом работы с Git важно провести его первоначальную настройку. Это поможет вам работать удобно и безопасно, а также сократит время на рутинные операции.

### Настройка имени и электронной почты

Первым делом установите своё имя и email — они будут использоваться для идентификации автора коммитов:

```csharp
git config --global user.name "Ваше Имя"
git config --global user.email "ваш_email@example.com"
```

Проверьте, что настройки сохранились:

```css
git config --global --list
```

### Настройка редактора по умолчанию

Git использует текстовый редактор для создания коммитов и некоторых операций. Вы можете установить удобный вам редактор, например, nano или vim:

- **nano:**  
    `git config --global core.editor "nano"`
- **vim:**  
    `git config --global core.editor "vim"`

### Полезные алиасы

Алиасы позволяют сократить длинные команды до удобных сокращений. Вот несколько примеров:

```csharp
git config --global alias.st status
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.ci commit
git config --global alias.last "log -1 HEAD"
```

Теперь вместо `git status` вы можете писать просто `git st`, а вместо `git checkout master` — `git co master`.

### Генерация и настройка SSH-ключей

SSH-ключи используются для безопасного доступа к удалённым репозиториям (GitHub, GitLab и другие). Настроить SSH-ключ очень просто:

- Сгенерируйте ключ (при необходимости замените email на свой):  
    `ssh-keygen -t ed25519 -C "ваш_email@example.com"`
- Запустите SSH-агент и добавьте ключ:
    
    ```bash
    eval "$(ssh-agent -s)"
    ssh-add ~/.ssh/id_ed25519
    ```
    
- Скопируйте публичный ключ (он будет выведен на экран командой ниже):  
    `cat ~/.ssh/id_ed25519.pub`
- Добавьте этот ключ в настройках вашего GitHub или GitLab аккаунта (раздел **SSH keys**).

### Проверка SSH-подключения

Убедитесь, что всё настроено правильно, выполнив проверочную команду:

```nginx
ssh -T git@github.com
```

Если вы увидели приветствие от GitHub — значит настройка завершена успешно!

Теперь вы готовы к полноценной работе с Git!
