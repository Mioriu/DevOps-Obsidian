# Отчёт о развертывании [Rocket.Chat](https://rocket.chat/) с защищённым удалённым доступом

## Цель проекта

Развернуть корпоративный мессенджер [Rocket.Chat](https://rocket.chat/) на локальном сервере и обеспечить безопасный доступ к нему из интернета через VPS с использованием шифрованного туннеля и HTTPS.

---

## Используемые компоненты и версии

|Компонент|Версия|Назначение|
|---|---|---|
|Ubuntu|24.04.4 LTS|Операционная система (обе машины)|
|[Rocket.Chat](https://rocket.chat/)|8.5.1|Корпоративный мессенджер|
|Node.js|22.22.23|Среда выполнения [Rocket.Chat](https://rocket.chat/)|
|Deno|2.3.1|Среда выполнения [Rocket.Chat](https://rocket.chat/)|
|MongoDB|8.3.0|База данных|
|WireGuard|—|VPN-туннель для шифрования трафика между серверами|
|Traefik|2.10.4|Реверс-прокси и HTTPS-терминация|
|certbot|—|Получение TLS-сертификатов Let's Encrypt|

Все версии зависимостей соответствуют официальным требованиям релиза [Rocket.Chat](https://rocket.chat/) 8.5.1. Все компоненты установлены нативно, без использования Docker.

Система построена на трёх ключевых компонентах, разделённых между двумя физическими машинами:

**Локальная машина** выполняет роль основного сервера приложений. На ней развёрнуты [Rocket.Chat](https://rocket.chat/) и MongoDB. База данных настроена на прослушивание только локального интерфейса, что исключает возможность прямого подключения к ней извне.

**VPS-сервер** выступает в роли пограничного шлюза. Он принимает пользовательский трафик из интернета, терминирует HTTPS-соединения и направляет расшифрованные запросы на локальную машину через защищённый туннель.

**WireGuard-туннель** связывает две машины в единую виртуальную сеть с адресацией `10.77.77.0/24`. Трафик между VPS и локальным сервером шифруется на всём пути.

## Выполненные работы

### Настройка локального сервера [Rocket.Chat](https://rocket.chat/)

На локальной машине развёрнут [Rocket.Chat](https://rocket.chat/) версии 8.5.1 согласно официальной документации для Ubuntu. Установлены все необходимые зависимости: Node.js 22.22.23, Deno 2.3.1, MongoDB 8.3.0.

MongoDB настроена на приём соединений только с локального интерфейса `127.0.0.1:27017`, что гарантирует её недоступность из интернета или через туннель. Приложение [Rocket.Chat](https://rocket.chat/) взаимодействует с базой данных напрямую, без сетевых посредников.

В конфигурации [Rocket.Chat](https://rocket.chat/) прописан внешний URL `https://rchat.mioryu.ru`, что обеспечивает корректную работу всех ссылок в уведомлениях, письмах и веб-интерфейсе.

### Организация защищённого канала связи

На VPS уже существовала рабочая сеть WireGuard с адресацией `10.77.77.0/24`, используемая как VPN с несколькими клиентами. Для подключения локальной машины в существующий конфиг добавлен новый узел с адресом `10.77.77.15`. Существующие клиенты VPN продолжили работу без изменений.

На локальной машине настроен клиент WireGuard с маршрутизацией только трафика виртуальной сети. Это решение гарантирует, что интернет-трафик локальной машины не проходит через VPS — через туннель направляются исключительно запросы к [Rocket.Chat](https://rocket.chat/).

### Настройка реверс-прокси и HTTPS

На VPS развёрнут Traefik версии 2.10.4 — реверс-прокси, работающий как системный сервис от непривилегированного пользователя. 

Traefik настроен на приём соединений на стандартных портах HTTP (80) и HTTPS (443). Реализована автоматическая обработка всего входящего трафика: любые HTTP-запросы перенаправляются на HTTPS с кодом 301, что исключает передачу данных в открытом виде.

Основной маршрут прокси принимает HTTPS-запросы к домену `rchat.mioryu.ru`, расшифровывает их и направляет на локальную машину через WireGuard-туннель по адресу `10.77.77.15:3000`. Таким образом, пользователи взаимодействуют с сервером через зашифрованное соединение на всём пути.

Для обслуживания HTTPS-соединений получен доверенный TLS-сертификат с помощью certbot от Let's Encrypt. Сертификат интегрирован в конфигурацию Traefik. 
### Настройка DNS

Для домена `mioryu.ru` создана A-запись, направляющая поддомен `rchat` на публичный IP-адрес VPS `77.221.157.189`. DNS-серверы предоставлены провайдером AEZA, распространение записи прошло успешно.
