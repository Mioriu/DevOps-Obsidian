## Приоритеты переменных в Ansible

**От самого низкого к самому высокому:**

1. **role defaults** (`defaults/main.yml`) — самый низкий приоритет
2. **inventory file/script group vars** — переменные групп в inventory
3. **inventory group_vars/all** — файл `group_vars/all.yml`
4. **playbook group_vars/all**
5. **inventory group_vars/*** — файлы групп
6. **playbook group_vars/***
7. **inventory file/script host vars** — переменные хостов в inventory
8. **inventory host_vars/*** — файлы хостов
9. **playbook host_vars/***
10. **host facts / cached set_facts** — собранные факты о хосте
11. **play vars**
12. **play vars_prompt**
13. **play vars_files**
14. **role vars** (`vars/main.yml`)
15. **block vars** (только в блоке)
16. **task vars** (только в задаче)
17. **include_vars**
18. **set_facts / registered vars**
19. **role (and include_role) params**
20. **include params**
21. **extra vars** (`-e` в командной строке) — **самый высокий приоритет**

## Что важно запомнить:

**Самый низкий:** `role defaults` — легко переопределить, используй для настраиваемых параметров

**Средний:** `role vars` — сложнее переопределить, используй для констант роли

**Самый высокий:** `extra vars (-e)` — переопределяет всё, используй для временных изменений

## Практический пример:

yamlcopy

```yaml
# defaults/main.ymlnginx_port: 80 # vars/main.yml  nginx_user: www-data # playbook.yml- hosts: web  vars:    nginx_port: 8080    # переопределит defaults    nginx_user: nginx   # НЕ переопределит vars/main.yml!  roles:    - nginx # командная строкаansible-playbook -e "nginx_port=9000" -e "nginx_user=root"# Переопределит ВСЁ
```

**На собесе спросят:** В чем разница между `defaults` и `vars` в роли?

**Ответ:** `defaults/` имеет самый низкий приоритет — для параметров которые пользователь настраивает. `vars/` имеет высокий приоритет — для констант роли которые не должны меняться.
